# UCST Website

A web-based college website for **UCST**, designed to present institutional information, campus visuals, faculty profiles, and important academic documents in one place.

## Overview

The UCST website provides visitors with access to:

- College information and website content
- Faculty profiles and professional details
- Faculty CVs and supporting documents
- Campus photographs and visual media
- Important institutional forms, notices, and documents

## Project Structure

```text
ucst/
├── documents/       # Institutional forms and documents
├── faculty/
│   ├── cv/          # Faculty CV documents
│   ├── cvimg/       # Faculty profile images
│   ├── cvjs/        # Faculty profile data
│   ├── faculty.js   # Faculty-related functionality
│   └── cvpages.js   # Faculty profile pages
├── media/
│   ├── campus/      # Campus photographs
│   ├── hero.mp4     # Homepage video
│   └── other assets
├── index.html       # Main website page
└── .gitignore
```

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

To run the website locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/harshaskolli-cmd/ucst.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
